# Layout review

Vault is a **tool**, not a SaaS landing page. Before drawing a new surface, state the user's immediate task and the data they need to decide. Give one action visual priority; group related facts; use compact rows for records and a meter only where it clarifies progress.

Reject reflexive three-column icon cards, identical card stacks, fake metrics, decorative blobs, emoji icons, and spacing or gradients without a purpose. Do not vary the layout for novelty if a familiar ledger pattern is clearer. Keep money aligned and scannable. A partial payment should visibly advance project progress without looking like a failure or an all-or-nothing decision.

Review desktop and narrow-phone layout; avoid horizontal overflow. Build on the existing green/neutral token palette and real user data.
